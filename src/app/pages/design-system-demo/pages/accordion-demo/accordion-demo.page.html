Basic Accordion

Simple accordion with title and content.

This is the basic accordion content. It can contain any HTML elements, components, or text content.

Accordions are useful for organizing large amounts of content into collapsible sections, reducing visual clutter while keeping information accessible.

Click the header area to toggle the expanded and collapsed states. The transition is animated for a smooth user experience.

With Subtitle

Accordion with title and subtitle text below it.

The subtitle appears directly below the title in a smaller, muted style. It provides additional context without cluttering the header.

Use subtitles to give users a preview of what the accordion section contains before they expand it.

Both the title and subtitle are fully visible in the collapsed state, so users can scan content quickly.

With Tags

Accordion headers can display chip tags with different variants.

A single default-variant tag is shown below the title. Tags are rendered as chip components and are useful for displaying metadata like counts or statuses.

Default tags use the neutral chip styling, making them unobtrusive while still conveying information.

In practice, this pattern is commonly used to show how many lessons or items are nested inside a section.

Multiple tags can be displayed side by side in the header. Each tag can have its own variant for visual distinction.

Here we combine a default tag ("3 Units") with a primary tag ("Active") to show both a count and a status.

Tags wrap naturally on smaller screens, maintaining readability across all device sizes.

Tags support a "custom" variant that lets you apply arbitrary CSS classes for unique styling needs.

The "Draft" tag above uses custom amber colors to indicate a work-in-progress state that doesn't fit the standard variants.

You can mix custom-styled tags with default tags in the same accordion header.

Icon Position

The chevron icon can be placed at the start or end of the header.

The expand/collapse chevron icon is positioned on the left side of the header. This is the default position.

Start-positioned icons work well when the accordion is the primary navigation element, drawing the eye to the toggle control first.

The icon rotates 180 degrees when the accordion is expanded, providing clear visual feedback of the current state.

The chevron icon is positioned on the right side of the header, after the title and tags.

End-positioned icons are a common pattern in settings pages and navigation menus where the title is the primary focus.

Note the slightly different icon size compared to the start position, optimized for each placement.

The chevron icon is hidden entirely using the showIcon input set to false.

Without an icon, the entire header area still acts as a click target to toggle the accordion.

This variant is useful when the accordion behavior is secondary or when space is limited.

With Menu Items

Accordions can have a 3-dot menu with action items (edit, delete, etc.).

Click the three-dot menu icon on the right side of the header to see the available actions: Edit, Duplicate, and Delete.

Menu items use the responsive menu component, which adapts to mobile by showing a bottom sheet instead of a dropdown.

Each menu item can have an icon, title, and state (e.g. "danger" for destructive actions like delete).

Custom Actions Template

Use a template reference to place custom action buttons in the header.

Add Lesson

The "Add Lesson" button in the header is injected via a custom #accordionActions template reference.

Custom actions are rendered in the header area and their click events do not propagate to the accordion toggle, so clicking the button won't expand or collapse the section.

This pattern is useful when you need inline actions that are more prominent than a menu dropdown.

Disabled State

A disabled accordion cannot be expanded or collapsed.

You should not be able to see this content because the accordion is disabled and collapsed by default.

Accordion Group (Single Expand)

Only one accordion can be open at a time. Opening one collapses the others.

This is Section A, which starts expanded. Try clicking Section B or C below to see this one automatically collapse.

Single-expand mode is the default behavior of the accordion group. It ensures only one section is visible at a time.

This pattern works well for FAQs, settings panels, or any content where focused attention on one section is preferred.

Section B is now open. Notice that Section A has automatically collapsed when you clicked here.

The accordion group component manages the state of its children, listening for expand events and collapsing siblings.

This behavior is handled entirely by the ds-accordion-group wrapper — no manual state management is needed.

Section C content. Only one section is visible at any given time in single-expand mode.

You can still collapse the currently open section by clicking its header again, leaving all sections collapsed.

The group also provides collapseAll() to programmatically close everything at once.
