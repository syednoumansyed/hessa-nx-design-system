# Responsive Token System

The nx design system employs a dynamic, CSS variable-based token system where spacing, corner radii, gaps, and typography automatically scale depending on the screen size. Breakpoints are defined at the `:root` level and adapt seamlessly using CSS media queries.

---

## 📱 Breakpoint Thresholds

The system has two distinct scaling tracks for viewport adaptability:

1. **Layout Tokens** (Spacing, Gaps, and Corner Radii):
   * **Mobile (Default):** $< 768\text{px}$
   * **Tablet (`md`):** $\ge 768\text{px}$
   * **Desktop (`xl`):** $\ge 1280\text{px}$

2. **Typography Tokens** (Font Sizes and Line Heights):
   * **Mobile (Default):** $< 768\text{px}$
   * **Tablet (`md`):** $\ge 768\text{px}$ to $1023\text{px}$
   * **Desktop (`lg`):** $\ge 1024\text{px}$

> [!WARNING]
> **Breakpoint Mismatch:** Spacing and layout tokens use a desktop breakpoint of **$1280\text{px}$**, while typography tokens transition to desktop scale at **$1024\text{px}$**. Ensure custom styles reference the correct media queries to prevent alignment glitches at intermediate screens.

## 🎨 Global Font Families

The application implements a clean font structure supporting LTR (English) and RTL (Arabic) styles.

* **LTR (English):** Defaults to `Nunito`, loaded dynamically.
* **RTL (Arabic):** Uses the custom `Lama Rounded` font loaded from local assets.

Font family configurations are set in the stylesheet using standard selectors based on the language attribute `lang="ar"` on the `<html>` node.

```scss
html {
  --ion-font-family: "Nunito", sans-serif;
  --hes-text-font: "Nunito", sans-serif;

  &[lang="ar"] {
    --ion-font-family: "Lama Rounded", sans-serif;
    --hes-text-font: "Lama Rounded", sans-serif;
  }
}
```

> [!NOTE]
> **No Theme Configuration for Color Mode:** There are no token changes or classes for light or dark mode. Only the typography and layout adapt based on device type, viewport sizes, and language directionality.
